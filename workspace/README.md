# 로컬 작업 영역

이 폴더의 내용은 로컬에서만 관리합니다. README 외 파일은 Git에 포함하지 않습니다.

```text
workspace/
├── inputs/metadata/   # 팀 CSV를 둘 경우의 선택 위치
├── artifacts/
│   ├── environments/ # 환경·패키지·검사 기록
│   ├── ubuntu/       # Ubuntu 실행 결과
│   └── logs/         # 설치·실행 로그
└── third_party/      # 고정 커밋의 공식 모델 소스
```

CSV와 원본 데이터는 외부 경로에 두고 설정에서 참조해도 됩니다.
CSV 선정·생성·재분할 기능은 제공하지 않습니다. 원본 이미지를 이 폴더로 복사할 필요도 없습니다.
위 하위 폴더는 입력을 배치하거나 스크립트를 실행할 때 사용합니다.zz
